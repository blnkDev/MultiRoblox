Help

Short answers to the usual questions, and what to try when something does not work.

Common questions

Why does the panel say "WAITING"?

A Roblox client that was opened before MultiRoblox is still holding the lock. Close every Roblox window (check Task Manager for RobloxPlayerBeta) and the panel turns into MULTI ON by itself. Only clients opened after MultiRoblox can run side by side.

Which browsers work for signing in?

Your default browser, if it is Firefox or a Chromium-based one (Edge, Chrome, Brave, Vivaldi). Anything else falls back to Edge or Chrome.

An account shows a letter instead of its picture

Roblox can take a while to prepare the picture of a new account, or hold it back while it is being reviewed. The colored letter is shown until the picture is ready, and pictures are refreshed every time the program opens (and at most every 12 hours). If it never appears, check your connection.

Does it work with the Roblox app from the Microsoft Store?

It is built for the Roblox client installed from the Roblox website (the roblox-player: protocol). The Microsoft Store version has not been tested.

Windows SmartScreen or my antivirus warns me. Is it a virus?

The program is new and not code-signed, which is enough to trigger a warning. You can read the whole source, build it yourself, or compare the SHA-256 hash of the download with the one published on the release page. If your antivirus quarantines the file, you can restore it or build from source.

How do updates work?

When a new release is published, an Update button appears in the title bar and opens the download page. Nothing is installed automatically, and you can turn the check off from the tray icon menu.

How do I remove it completely?

Delete the program and the %APPDATA%\MultiRoblox folder. Nothing else is installed or changed on your PC.

Can I lock MultiRoblox with a password?

Yes. Right-click the tray icon and choose Set password.... MultiRoblox will then ask for it whenever it opens. Choose Lock now from the same menu to hide the window and require the password to bring it back; multi-client keeps running while it is locked. The password only locks the program window: your accounts file is still protected by Windows (DPAPI), not by this password.

I forgot my password

Close MultiRoblox, delete %APPDATA%\MultiRoblox\lock.dat and open it again: the lock is gone and your accounts are untouched. This is why the lock is a convenience, not strong protection against someone who has access to your Windows account.

When something does not work

An account says "login expired"

Roblox ended that login, which happens after a new sign-in elsewhere, a password change or a long time without use. Click + Add account and sign in to it again: the existing entry is updated.

"Roblox did not open" for an account

No Roblox client appeared within about 45 seconds. Make sure Roblox is installed from roblox.com and opens normally on its own, then try again. Roblox also limits how fast you can start clients, so launching a few at a time helps. The details are in %APPDATA%\MultiRoblox\log.txt.

The second client still closes the first one

Check that the panel says MULTI ON before you open the clients. If it does and the first client still closes, Roblox may have changed the mechanism MultiRoblox relies on. That is outside the program's control, and the project cannot work around it.

The sign-in browser opens but the account is never added

The program waits up to 10 minutes for you to finish signing in. If the login page loaded but nothing happens afterwards, check log.txt: it lists every step of the sign-in. Closing the browser window by hand cancels the attempt.

"Could not check for updates"

The update check needs to reach api.github.com. It can fail behind some networks or when GitHub rate-limits your connection. It is harmless: try again later from the tray menu.

Report a problem

Open an issue on GitHub and include your Windows version, the MultiRoblox version (shown in the title bar), what you did and what happened.

Click Open log at the bottom right of the window (or use the tray menu) to open log.txt. It never contains your cookie, but look through it before posting and remove anything personal. Never share accounts.dat.
