Download for Windows

Windows 10 / 11 · free & open source (MIT) · a ~60 KB download, no installer

All versions · Changelog

What you need
  • Windows 10 or 11
  • Roblox installed from roblox.com
  • Firefox, Edge, Chrome, Brave or Vivaldi to sign in
  • Nothing else: the .NET Framework it uses ships with Windows

Install in three steps

Download

Use the button above. You get a small zip file named MultiRoblox-vX.Y.Z.zip.

Extract

Extract it anywhere you like. There is no installer, and nothing is written outside %APPDATA%\MultiRoblox.

Run it

Open MultiRoblox.exe. If SmartScreen warns you, choose More info → Run anyway. Then follow the guide.

What's new in the latest release

The release notes are on the release page.

Advanced

You do not need any of this to use the program. It is here for people who like to double-check what they download.

Verify the download (SHA-256)

Open PowerShell where you saved the zip and compare the result with the hash published on the release.

Get-FileHash .\MultiRoblox-vX.Y.Z.zip -Algorithm SHA256

Expected SHA-256 for the latest release:

Shown on the release page (SHA256SUMS.txt).
Build it yourself

Nothing to install: the C# compiler already ships with Windows.

git clone https://github.com/blnkDev/MultiRoblox.git
cd MultiRoblox
.\build.ps1
