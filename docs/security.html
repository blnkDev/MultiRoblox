Security and privacy

An account manager handles sensitive data, so it is open source and its behavior is short enough to list here.

What is stored

FileWhat it holdsProtection
accounts.datYour accounts: Roblox user ID, name, nickname and the session cookieEncrypted with the Windows DPAPI, readable only by your Windows user on this PC
favs.txtFavorite games (Place ID and name)Plain text, nothing sensitive
place.txtThe last Place ID you launchedPlain text, nothing sensitive
log.txtDiagnostic messages. It never contains the cookiePlain text
lock.datOnly if you set a password: a salted PBKDF2 hash of it. The password itself is never storedHashed, 100,000 rounds
avatars\Cached profile pictures of your accounts: public images from Roblox, refreshed every 12 hoursPlain image files, nothing sensitive
update-check-off.txtOnly exists if you turned off update checks-

All of it lives in %APPDATA%\MultiRoblox. No Roblox password is ever stored. To remove everything, delete that folder.

The optional password lock only locks the program window. It does not encrypt your accounts any further: accounts.dat stays protected by the Windows DPAPI, which ties it to your Windows user. Treat the lock as protection against casual use of your PC, not against someone who controls your Windows account.

Who it talks to

HostWhyCookie sent?
*.roblox.comChecking logins, one-time sign-in tickets to launch games, online status, game names and player countsOnly for login checks, tickets and online status, and only to roblox.com
Roblox image CDNGame icons and profile pictures (only Roblox's own CDN, over https)No
api.github.comThe optional update checkNo. GitHub sees your IP address like in any web request

Nothing else: no analytics, no crash reports, no server of its own.

How sign-in works

When you click + Add account, the program opens your default browser with a temporary, empty profile and a local debugging port. Chromium-based browsers (Edge, Chrome, Brave, Vivaldi) use the Chrome DevTools Protocol; Firefox uses WebDriver BiDi. Once you are signed in, the cookie is read through that channel, validated with Roblox, and the browser is closed.

The temporary profile is deleted afterwards, and only processes that use that unique profile are closed. Your own browser data, tabs and saved passwords are never touched.

Verify it yourself

Read and build the code

  • The whole program is one C# file on GitHub.
  • The compiler already ships with Windows: run .\build.ps1 and compare.

Check the download

  • Every release lists a SHA-256 hash. Compare it with Get-FileHash.
  • The executable is not code-signed, so SmartScreen may warn on the first run.

Read this before you use it

  • MultiRoblox is not affiliated with, approved by or endorsed by Roblox Corporation.
  • Running several clients may violate Roblox's Terms of Use or the rules of specific games, and can get accounts punished or banned. Use it at your own risk, preferably with disposable accounts.
  • Anyone with the cookie can enter the account without the password or 2FA, so never share accounts.dat or the %APPDATA%\MultiRoblox folder.
  • It relies on a mechanism of the Roblox client that may change or stop working with any update.
  • It is not for cheating or automation: there are no macros, no anti-AFK and no game automation.
