Guide

From download to your first multi-account launch, plus the tips that save time.

Getting started

  1. Download and run it

    Get the latest zip from the Download page, extract it anywhere and run MultiRoblox.exe. The program is not code-signed, so Windows SmartScreen may warn you the first time (More info → Run anyway).

  2. Close every Roblox window

    The panel at the top shows WAITING while a client opened before MultiRoblox is still holding the lock. Close all Roblox windows and it turns into MULTI ON by itself.

  3. Add your accounts

    Click + Add account. Your browser opens on roblox.com/login: sign in as usual, captcha and 2FA included. The program waits up to 10 minutes, notices the login, closes the temporary browser and adds the account. Repeat for each account. Every sign-in uses a fresh browser profile, so you never need to log out of another account first.

  4. Pick a game

    Type the game's Place ID, the number in its address: roblox.com/games/<Place ID>/Name. The name, icon and player count appear to confirm it is the right one. Click the star to add it to your favorites.

  5. Select accounts and press Play

    Select one or more accounts (Ctrl or Shift for several) and click Play. The clients open one by one; each row shows open once its client is up, or a red message if it failed.

  6. Arrange and follow

    Tile windows lines the clients up in a grid. Follow user... joins the server where a friend (or another account of yours) is playing.

Shortcuts and tips

To do thisDo this
Select several accountsCtrl+click or Shift+click
Set a nicknameDouble-click the account and type right on its row (Enter saves, Esc cancels), or select it and click Nickname
Reorder accountsDrag and drop, or Alt+↑ / Alt+↓ (moves all selected)
Favorite a gameClick the star next to the Place ID, then pick it later from the Favorites dropdown
Refresh online statusClick ↻ Status
Close one account's clientRight-click the account and choose Close client. Only clients opened by MultiRoblox can be closed this way
Lock the programTray icon menu → Set password.... It is asked when the program opens. Lock now in the same menu hides the window until the password is typed again. Change or remove it from that menu too
See what went wrongClick Open log (bottom right), or use the tray menu. Open data folder is there too
Keep it running in the backgroundMinimize it to the taskbar like any other app: multi-client keeps working. Closing the window quits the program
Tray menuShow, Lock now (when a password is set), Check for updates now, Check for updates automatically, Open log, Open data folder, Set password..., Exit
Quit and turn multi-client offClose the window, or Exit from the tray menu

What the labels mean

LabelMeaning
MULTI ONMulti-client is active. Clients you open now can run side by side.
WAITINGA Roblox client opened before MultiRoblox is holding the lock. Close all of them.
openThe client for this account is running.
in game: nameThe account is playing that game right now.
online (website)The account is online on the Roblox website or app, not in a game.
offlineThe account is not online.
Dot on the pictureGreen: in a game. Blue: online. Orange: in Roblox Studio. Gray: offline. No dot: not checked yet.
login expiredRoblox ended that login (new sign-in elsewhere, password change...). Add the account again.
Roblox did not openNo client appeared within about 45 seconds. See the Help page.
rate limitedRoblox is limiting how fast you can start clients. Wait a minute and try again.
locked or restrictedRoblox refused the request (HTTP 403). The account may be locked or under review: check it on roblox.com.
could not reach RobloxThere is no connection to Roblox right now. Check your internet and try again.

Where your data lives

Everything is stored in %APPDATA%\MultiRoblox. Delete that folder and the program to remove all traces. Details on the Security page.
